## Current end-to-end design

```text
Learner observation history
        ↓
ObservationEncoder: response + outcome → 256-D observation
        ↓
TemporalLearnerEncoder → 128-D learner state

Instructional action
        ↓
ActionEncoder: categorical fields + prompt → 32-D action

learner state [128] + action [32]
        ↓
ActionConditionedPredictor
        ↓
predicted next learner state [128]
        ↓
compare predictions for valid actions with goal state [128]
        ↓
research planner recommends action with smallest cosine distance
```

The components, joint action-conditioned training loop, no-action baseline, and one-step
planner are implemented. A generic 64-concept ontology and linear state probe are also
implemented. Concept alignment, action sensitivity, and evaluation with more tutoring data
remain future work.

In the web application, that recommendation is shadow-only: the API uniformly samples
the delivered action and records the assignment probabilities. The inference service may
be unavailable without stopping random assignment. Stored predicted states are not
observed learner outcomes or proof of mastery.
